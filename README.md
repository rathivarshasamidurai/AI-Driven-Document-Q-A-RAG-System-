# Advanced RAG Document Chatbot

An AI-powered chatbot that answers questions from PDF documents using Advanced Retrieval-Augmented Generation (RAG).

**Technologies:** Python, Google Colab, FAISS, Sentence Transformers, BM25, Cross-Encoder, and Gradio.

**Features:**
- PDF text extraction and chunking
- Hybrid search and reranking
- AI-generated answers
- Source page references

**How to run:** Open the `.ipynb` notebook in Google Colab and execute the cells in order.
